# 产品对照：macOS 与 Linux 0.2

基准为 `main @ 54ef72b` 的 Swift 实现，覆盖 `AppSettings`、`AppDelegate`、`SettingsView`、`FloatingBall`、`BallSelection`、`CaptureSelection`、`CapturePet`、`OverlayController` 和 `LanguageDetector`。下表描述实现与平台差异；实机通过情况以 5080 回归报告为准。

| 功能 / UI 元素 | macOS 基准 | Linux 0.2 实现 / 限制 |
| --- | --- | --- |
| 功能模式 | 翻译 / OCR 识别 / OCR翻译，分段选择 | 相同三模式、分段选择；设置和菜单同步 |
| 全局快捷键 | Command+Shift+T 执行所选模式 | X11 为 Ctrl+Shift+T；Wayland 在系统中绑定 `--action primary`，合成器禁止任意应用全局拦截按键 |
| 翻译服务 | OpenAI / Anthropic / Ollama | 相同协议、默认地址、模型字段、独立配置持久化 |
| 本机模型发现 | 刷新、加载、空列表、错误、自动选模型 | 同样的状态与选择行为；只连接已有 Ollama，不下载模型 |
| API Key | 密码遮罩与显示 / 隐藏 | 相同显隐控件；当前用户配置权限 600，均未加密 |
| 源 / 目标语言 | 自动源语言与 14 种目标语言 | 相同语言集合 |
| 独立语言判断 | NaturalLanguage，置信度 ≥0.65，中文两种字形都匹配 | 本地 langdetect 55 种语言模型，固定随机种子、相同阈值与中文匹配规则；Apple 框架不支持 Linux，识别概率与边界结果不保证逐字相同 |
| 已是目标语言 | 剪贴板翻译不发请求、不显示字幕；OCR翻译保留识别文字 | 相同请求与结果规则，识别在后台执行 |
| 自动监听 | 剪贴板变化触发翻译，避免译文循环 | 同样的去重与复制保护 |
| 浮球皮肤 | 经典棱镜 / 橘猫 / 柴犬 / 熊猫 / 小黄鸡 | 相同五种皮肤、配色与 72 pt 画布 / 23 pt 半径；Qt 原生矢量绘制 |
| 宠物脸部 | 耳朵、斑纹、眼睛、鼻子、嘴、腮红 | 相同角色图形与状态表情，复用截图头部绘制 |
| 动画 | 呼吸、悬停放大、点击收缩、眨眼、视线跟随、忙碌环、开心跳动、失败摇头、90秒后打瞌睡 | 同样的状态和时序；减少动态效果停用连续运动 |
| 自动监听标记 | 宠物戴耳机 | 同一监听状态驱动耳机显示 |
| 浮球移动 | 5 pt 移动优先于 0.4秒长按，侧边48 pt 吸附、6 pt 间距，位置记忆 | 同样的阈值、吸附、存储、屏幕变化后保持可达 |
| 普通浮球菜单 | 翻译、两种 OCR、快捷键模式、监听、皮肤、显示、设置、退出 | 同样入口、勾选状态；另保留 Linux 图片 OCR 入口 |
| 长按环形菜单 | 0.4秒，OCR / OCR翻译 / 自动监听三分区 | 相同方向、36 / 76 / 96 pt 半径、接缝迟滞、释放执行 |
| 环形菜单取消 | 中央及原按下位置死区、移出范围、Esc、失去活动状态 | 相同取消规则；OCR忙时两种OCR入口禁用，监听仍可切换 |
| 环形标签 | 悬停0.5秒后出现，避开环形分区，屏幕边缘夹取 | 相同延迟与避让；Linux 使用半透明材质，AppKit 背景模糊不可直接复用 |
| 截图选区 | 背景静帧、遮罩、双线边框、十字光标、尺寸读数，正反拖动、Esc/右键取消 | 相同构成；X11 真全屏并按实际全局位置绘制 / 裁剪，修复顶栏偏移 |
| 截图宠物 | 选区左上角 approved A pose，四种宠物；经典无宠物 | 原路径坐标移植，前后肢 / 鸡翅分层，复用相同头部 |
| 跨屏截图 | 全局区域、多屏原点、不同像素比合成 | X11 全局区域和混合 DPI 合成；物理多屏仍需实机验证 |
| OCR 引擎 | Apple Vision，按语言识别 | 本机 Tesseract；Apple Vision 不支持 Linux，字符精度、混排空格与语言包可用性不同 |
| 截屏授权 | macOS 录屏权限指引 | X11 直接捕获；Wayland 使用桌面 portal 授权，实际可选区域由系统后端决定 |
| 字幕外观 | 半透明黑色、16 pt 圆角，原文次级 / 译文半粗、居中、紧凑宽度 | 同样的信息层次、圆角、字号和紧凑布局；字体栅格化随平台字体变化 |
| 字幕位置 / 长文本 | 内容按中心调整、限屏、滚动、文本选择与复制 | 相同中心锚点、长文滚动、原生 Ctrl+C / Ctrl+A；位置随重启保留 |
| 字幕状态 | 加载、成功、错误；悬停暂停、定时关闭、锁定、解锁拖动 | 同样状态；图钉悬停显示或锁定常驻，加载不自动关闭 |
| 字幕外部点击关闭 | 全局鼠标监听，未固定字幕关闭 | X11 非独占 XInput2 鼠标事件；Wayland 仅本应用外部点击可观察，合成器隔离其他应用输入 |
| 设置页面 | 单一滚动页面，功能模式 / 协议 / 语言 / 字幕 / 快捷键；变更持久化 | 相同顺序、分段选项、滑块、皮肤、即时保存；保留 OCR语言包及减少动态效果选项 |
| 系统外观与键盘 | 系统明暗主题、减少动态效果、原生编辑快捷键 | Qt系统调色板、GNOME减少动画偏好与显式选项、焦点和 Ctrl 编辑快捷键 |
| 系统入口 | macOS菜单栏，跨空间悬浮面板 | Linux托盘及浮球；GNOME托盘取决于扩展，Wayland置顶 / 窗口位置取决于合成器 |
| 启动 / 退出 | 持久化设置，单进程桌面工具 | Linux单实例 IPC；长路径回退到权限700的短目录，退出清理 socket / 锁 |

尚需区分的验证范围：Docker/Xvfb 和 Openbox 顶栏夹具不代替 GNOME 实机；真实 Wayland/portal、托盘、物理多屏/HiDPI、云端付费接口、主机 apt 安装/卸载和桌面启动器需对应环境。Tesseract 中英混排空格和此前 `QPainter::end` 警告沿用已知问题，不能据实现对照表认定它们已经解决。
